🧪 Transmission Resilience & Network Fault Simulator
Interactive Experimentation

Use this simulator during viva demonstrations to show your professors how RuralLink handles transmission interruptions, exponential backoff retries, and offline queueing.

1. Packet Drop (HTTP 503)

Simulates link corruption. Client will automatically buffer the report into local storage and initiate exponential backoff retries.

2. Gateway Timeout (HTTP 504)

Simulates rural radio link timeout. Client transport catches socket timeout and enqueues payload with duplicate key intact.

3. High Latency Injection

Injects a 2.5 second artificial transmission delay to illustrate round-trip time (RTT) overhead and asynchronous UI responsiveness.

🦈 Wireshark Packet Sniffing & Analysis Guide
Capture Port 5000

How to Capture RuralLink Packets in Wireshark:

  1. Launch Wireshark on your computer.
  2. For local development on 127.0.0.1, double-click "Adapter for loopback traffic capture" (or Npcap Loopback Adapter). If testing across two computers on LAN, select your Wi-Fi or Ethernet adapter.
  3. Paste any of the display filters below into the green filter bar at the top of Wireshark and hit Enter.
  4. Submit a report in the Rural Clinic Portal and watch the TCP 3-way handshake and HTTP packets appear live!

Key Wireshark Display Filters Cheat Sheet:

Objective / Scenario Wireshark Display Filter Protocol Stack Details Action
Filter All RuralLink HTTP Traffic http && tcp.port == 5000 Captures all application-layer requests/responses
Capture Report Submission POSTs http.request.method == "POST" && http.request.uri contains "/api/reports" Isolates patient data & multipart PDF packets
Capture Server Acknowledgements (201) http.response.code == 201 Inspects server ACK token & SHA-256 verification
Capture Duplicate Rejections (409) http.response.code == 409 Demonstrates idempotency key collision rejection
Inspect TCP 3-Way Handshake tcp.flags.syn == 1 && tcp.port == 5000 Shows SYN and SYN-ACK packets initiating session
Filter Hospital Tele-Consultations http.request.uri contains "/response" Inspects doctor consultation advice packet
